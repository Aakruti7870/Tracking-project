# Hero PR checklist

Before merge:
- all required CI checks green;
- Login Light and Dark manually verified;
- Customer Home Light and Dark manually verified;
- web zoom 80%, 100%, 120% checked;
- narrow Android/mobile width checked;
- no clipped plant, silo, mixer, or hero subject;
- no changes to auth, KYC, package ID, signing, SHA/fingerprint, App Links, backend routes, or production secrets.
