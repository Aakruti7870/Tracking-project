# Approved visual direction

The Login and post-login Customer Home hero treatment must match the approved light/dark direction shown in the design review: bright clean industrial RMC scene for Light Mode, graphite/night industrial RMC scene for Dark Mode, orange interaction accent, green reserved for verified/status semantics, and full subject visibility without crop.

Implementation priority is deterministic rendering: theme switch first, full-image visibility second, then decorative gradient treatment. No build may trade these rules for a more aggressive crop.
