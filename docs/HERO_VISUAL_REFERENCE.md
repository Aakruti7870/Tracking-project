# Approved visual direction

The Login artwork must match the approved light/dark direction shown in the design review: bright clean industrial RMC scene for Light Mode, graphite/night industrial RMC scene for Dark Mode, orange interaction accent, green reserved for verified/status semantics, and full subject visibility without crop.

Post-login homes use native, theme-aware surfaces instead of promotional artwork. Their compact greetings, backend-derived KPIs, live work or delivery state, and contextual primary actions must remain readable in both themes without displacing operational information below the fold.

For Login, implementation priority is deterministic rendering: theme switch first, full-image visibility second, then decorative gradient treatment. No build may trade these rules for a more aggressive crop.
