# TrackMyRMC

Production repository for the TrackMyRMC mobile/web application and FastAPI backend.

Primary source areas:
- `frontend/` — Expo / React Native application
- `backend/` — FastAPI API and services
- `docs/` — technical and policy documentation
- `memory/PRD.md` — product requirements and implementation history

Validation is enforced by the workflows under `.github/workflows/`.
